# Xmode — cửa hàng thời trang

Ứng dụng ASP.NET Core MVC/Razor và SQL Server cho cửa hàng thời trang. Xmode hỗ trợ danh mục, sản phẩm theo màu/size, ảnh Cloudinary, giỏ hàng, đơn COD và quản trị nội dung.

- [Cấu hình và khởi tạo database, Admin](docs/database/README.md)
- [Màn hình, kiểm thử và phạm vi Xmode](docs/xmode/README.md)

Ứng dụng **không tự chạy migration hoặc seed khi khởi động**. Database mới không tự tạo danh mục, sản phẩm, bài viết hoặc nội dung trang chủ. Admin tạo danh mục và dữ liệu cửa hàng qua giao diện.
